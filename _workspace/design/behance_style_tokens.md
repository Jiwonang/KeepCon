# KeepCon 디자인 방향 — 정본: KeepCon 틀 이미지 (라이트) + Behance 배치 참고

> 정정(2026-07-07): 최초 Behance 스크린샷은 다크였으나, 사용자가 **KeepCon 실제 틀 이미지(화이트 모드)** 를 제공하고
> "**기본은 화이트, 다크모드는 설정에서 지원**"으로 방향을 확정함.
> → **색/구조 정본 = KeepCon 틀 이미지(라이트)**. Behance = 정돈된 배치·라운드·플레이풀 무드의 참고.
> 상태: 분석 완료. 하단 내비 구조만 사용자 확인 대기 → 확인 후 공유 테마(SSOT)로 구현.

## 테마 정책
- **기본 = 라이트(화이트)**. 다크모드는 **설정('마이')** 에서 토글. `ThemeMode`(system/light/dark)를 설정 저장소 + provider로 관리.
- 현재 앱은 `Theme.of(context).colorScheme` 토큰을 쓰므로 테마 교체로 전 페이지 반영.

## 다크모드 토큰 (설정 시)
라이트의 역상: bg near-black(#141418), 카드 #1E1E24, 텍스트 #F5F5F7, primary 민트-그린 유지(#22D89A), danger 유지. Behance 다크 무드가 여기 참고가 됨.

## 홈(메인) 화면 요소 (틀 이미지 기준)
1. 인사 헤더: "안녕하세요 👋" + "내 기프티콘"(볼드) + 알림 벨(초록 뱃지) + 아바타(사용자 이니셜, 다크 원)
2. 검색바(회색 pill, "브랜드, 상품명 검색") + 필터 버튼(다크 원, 슬라이더 아이콘)
3. 만료 알림 배너: 다크 카드 + 초록 시계 아이콘 + "OO 곧 만료!" + "N개가 7일 내 만료됩니다" + "확인" pill(초록)
4. 요약 통계 3카드: 보유중(count) / 만료 임박(count, 7일 내) / 총금액(sum, 원)
5. 섹션 헤더: "전체 N개" + "만료순 ↓"(정렬, 초록)
6. 2열 기프티콘 카드: 이미지 top + D-day 뱃지(pill, 대비색) + 브랜드(muted) + 상품명(볼드) + 가격(볼드, 원) + 만료일(시계, 임박 시 빨강)
7. 하단 내비: 홈 / 중앙 다크 +(추가) / 마이  ← **구조 최종확인 필요**

## 계약 변경 (필요)
- **Gifticon.price 추가** (int, KRW). 카드 가격 표시 + 총금액 통계에 필요.
- 통계(보유중/만료임박/총금액)는 소비자(main)에서 원천 목록으로 계산.
- 설정(ThemeMode) 저장소 + provider = 공유 관심사 → contract/shared.

## 일러스트/이미지
틀의 카드 이미지는 실제 기프티콘 사진. 데모에선 카테고리별 placeholder 이미지/색블록 사용. 사용자 에셋 제공 시 교체.

## 구현 순서 (내비 확정 후)
1. contract-architect: 라이트/다크 ThemeData + 토큰을 lib/shared/theme/ SSOT로. Gifticon.price 추가. ThemeMode 설정 provider.
2. main(홈) 재디자인: 헤더/검색/배너/통계/카드/정렬 — 토큰만 소비.
3. 마이(설정) 페이지: 다크모드 토글 등.
4. 셸: 확정된 하단 내비 구조로.
