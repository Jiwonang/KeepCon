작성: 2026-07-08 · 담당: share-page-dev · 모드: **프론트 전용 하드코딩(증분 확장)**

> ⚠️ **이 문서는 2026-07-08 프로토타입 시점의 기록이다 — 아래 "전제"·"상호작용" 절의 지시는 더 이상 유효하지 않다.**

> `lib/shared/models/group.dart`·`share.dart`와 `ShareRepository`가 **정본(SSOT)** 이 되었고,

> - "`lib/shared`에 그룹/공유 모델을 추가하지 않는다", "`lib/features/share/` 로컬 타입으로 둔다",

> - **기능 목록은 "무엇을 만드는가"의 범위만 유효하다** — 각 항목 괄호 안의 "UI만"·"하드코딩"·
>   "로컬 상태로 시연" 같은 **구현 방식** 표기는 v2.2 계약 소비 전환으로 대부분 무효다. 실제 동작은
>   항상 `lib/shared/repositories/share_repository.dart`와 `_workspace/01_contract_dependency_matrix.md`로
>   확인한다. (기능 목록이 통째로 유효하다고 적어 두었던 탓에 참여 흐름이 승인제로 바뀐 뒤에도
>   옛 서술이 보증받은 채 남아 있었다.)
> 현재 계약의 실제 상태는 `_workspace/01_contract_dependency_matrix.md`를 본다.

## 전제
- **프론트만 하드코딩.** `lib/shared/`(계약)에 그룹/공유 모델을 추가하지 않는다. 그룹 도메인 타입은
  `lib/features/share/` 하위 로컬 타입으로 두고 "프로토타입 · 계약 v1 확정 후 이관" 주석을 단다.
- 기존 `Gifticon`/`User`/`GifticonRepository` 계약은 **소비하지 않고**(아직 연동 X) 화면 내 로컬 하드코딩
  데이터로 채운다. ★표시(메인/스캔 데이터 공유)는 후속 연동 지점으로 주석만 남긴다.
- 색/폰트/라운드/그림자는 전부 `Theme.of(context)` + `ShareThemeTokens`(share_tokens.dart) 소비. 색 하드코딩 금지. 라이트/다크 모두 대응.
- 기존 `share_page.dart` 구조를 존중하며 확장. 셸 네비 push 패턴(`MaterialPageRoute`)을 따른다.

## 사용자 결정
- **프리미엄 게이팅 없음** — 무료/프리미엄 구분 UI 미도입. 모든 기능 제한 없이 사용 가능(유료화 추후 설계).
- **전체 화면 push** — 그룹 상세/멤버 관리 등 정보량 많은 화면은 전체 페이지, 생성·참여·초대 등 짧은 입력은 바텀시트.

## 기능 트리 (구현 대상)
### 그룹 관리
- 그룹 생성 (바텀시트: 그룹명·이모지/아이콘 선택)
- 그룹 참여 **요청** (바텀시트: 6자리 초대코드 또는 링크 토큰 입력 → 방장 승인 대기)
  - ⚠️ 즉시 합류가 아니다. 링크·코드 소지는 **요청 자격**일 뿐이며 방장이 승인해야 멤버가 된다
    (계약 v3.8 — `_workspace/01_contract_dependency_matrix.md`).
  - 요청자에게는 **공유 탭**에 대기·거절만 보인다 — 승인되면 위 그룹 목록에 나타난다.
- 그룹 정보 화면 (그룹명·대표자(방장)·멤버 수·멤버 목록)
  - 그룹 삭제(방장) / 나가기(멤버). 방장이 나갈 때 소유권 이전 UI.
### 멤버 초대
- 초대 방식: 초대 링크(복사·공유) + **6자리 초대코드**(방장이 발급, 5분)
- 참여 요청 승인/거절 (방장 전용 — 그룹 상세의 대기 목록)
  - 정원은 **승인 시점**에 본다(대기자는 자리를 차지하지 않는다).
  - 거절은 기록으로 남긴다 — 비멤버는 그룹 알림을 못 읽으므로 요청자가 결과를 아는 유일한 경로다.
- 초대 권한 지정 (방장 한정 토글 — `ShareRepository.setInviteOwnerOnly`로 그룹 정책에 **영속**된다)
- 링크 유효기간: **24시간 고정**(선택 UI 없음 — 남은 기간 표시만). 만료 시 방장이 링크 재발급으로 창을 다시 연다
- 초대코드 유효기간: **5분 고정**(OTP). 만료는 정상 경로이며 방장이 다시 발급한다
### 그룹 공유 기프티콘
- 기프티콘 그룹에 공유 (바텀시트/화면 — 내 기프티콘 목록에서 선택. `ShareRepository.shareGifticon`)
- 그룹 내 공유 기프티콘 목록 조회
- 사용중 잠김 상태 (다른 멤버에게 잠김 배지·비활성)
- 찜 기능 (사용 예정 표시 토글 — 그룹 내 알림 역할)
- 사용 완료 처리 → 목록/상태 동기화 (`ShareRepository.markUsed` — 원본 기프티콘도 `GifticonStatus.used`로 동기화)
- 사용 이력 로그 조회 (전체 화면)
- 공유 취소(회수)
- 그룹 알림 (등록/만료임박/사용완료) — 알림 목록 화면 또는 배너

## 상호작용(로컬 상태로 시연)
찜 토글, 사용완료 처리, 공유취소, 잠김 표시 등은 로컬 상태(StatefulWidget 또는 share 스코프 provider)로
실제 반응하게 만든다. `lib/shared` provider/repository는 건드리지 않는다.
