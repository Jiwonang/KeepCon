# 공유(그룹) 페이지 — 하드코딩 프론트 구현 스펙

작성: 2026-07-08 · 담당: share-page-dev · 모드: **프론트 전용 하드코딩(증분 확장)**

## 전제
- **프론트만 하드코딩.** `lib/shared/`(계약)에 그룹/공유 모델을 추가하지 않는다. 그룹 도메인 타입은
  `lib/features/share/` 하위 로컬 타입으로 두고 "프로토타입 · 계약 v1 확정 후 이관" 주석을 단다.
- 기존 `Gifticon`/`User`/`GifticonRepository` 계약은 **소비하지 않고**(아직 연동 X) 화면 내 로컬 하드코딩
  데이터로 채운다. ★표시(메인/스캔 데이터 공유)는 후속 연동 지점으로 주석만 남긴다.
- 색/폰트/라운드/그림자는 전부 `Theme.of(context)` + `ShareThemeTokens`(share_tokens.dart) 소비. 색 하드코딩 금지. 라이트/다크 모두 대응.
- 기존 `share_page.dart` 구조를 존중하며 확장. 셸 네비 push 패턴(`MaterialPageRoute`)을 따른다.

## 사용자 결정
- **프리미엄 게이팅 없음** — 무료/프리미엄 구분 UI 미도입. 모든 기능 제한 없이 사용 가능(유료화 추후 설계).
- **전체 화면 push** — 그룹 상세/멤버 관리 등 정보량 많은 화면은 전체 페이지, 생성·참여·초대 등 짧은 입력은 바텀시트.

## 기능 트리 (구현 대상)
### 그룹 관리
- 그룹 생성 (바텀시트: 그룹명·이모지/아이콘 선택)
- 그룹 참여 (바텀시트: 초대코드 입력)
- 그룹 정보 화면 (그룹명·대표자(방장)·멤버 수·멤버 목록)
  - 그룹 삭제(방장) / 나가기(멤버). 방장이 나갈 때 소유권 이전 UI.
### 멤버 초대
- 초대 방식: 초대 URL + 초대코드 (복사 버튼)
- 초대 권한 지정 (방장 한정 토글 — UI만)
- 초대 유효기간: **24시간 고정**(선택 UI 없음 — 남은 기간 표시만). 만료 시 방장이 코드 재발급으로 창을 다시 연다
### 그룹 공유 기프티콘
- 기프티콘 그룹에 공유 (바텀시트/화면 — 내 기프티콘 목록에서 선택, 하드코딩)
- 그룹 내 공유 기프티콘 목록 조회
- 사용중 잠김 상태 (다른 멤버에게 잠김 배지·비활성)
- 찜 기능 (사용 예정 표시 토글 — 그룹 내 알림 역할)
- 사용 완료 처리 → 목록/상태 동기화(로컬 상태로 시연)
- 사용 이력 로그 조회 (전체 화면)
- 공유 취소(회수)
- 그룹 알림 (등록/만료임박/사용완료) — 알림 목록 화면 또는 배너

## 상호작용(로컬 상태로 시연)
찜 토글, 사용완료 처리, 공유취소, 잠김 표시 등은 로컬 상태(StatefulWidget 또는 share 스코프 provider)로
실제 반응하게 만든다. `lib/shared` provider/repository는 건드리지 않는다.
